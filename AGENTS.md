# AGENTS.md — spoken_dict_th

## What this is
Open Spoken Dictionary (OSD) — a collection of 40,000+ Thai word pronunciation MP3 audio files for language learners and accessibility tools.

## Stack
- MP3 audio files
- Text word list (words.txt)

## Build
No build step — static data repository.

## Run
Browse `sounds/th/` directory for MP3 files. Use `words.txt` for the word list.

## Structure
- `sounds/th/*.mp3` — Thai word pronunciation audio files
- `words.txt` — word list
- `README.md` — project documentation
- `LICENSE` — GPLv3

## Conventions
- Audio files named as `<thai_word>.mp3`
- GPLv3 license — derivative works must also be GPLv3.
